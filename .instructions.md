# Micro Manager Project Instructions

## Widget Composition

**DO NOT create `_build*` functions.** Instead, create private widget classes.

❌ AVOID:
```dart
Widget _buildStatusCard(...) {
  return Container(...);
}
```

✅ DO THIS:
```dart
class _StatusCard extends StatelessWidget {
  // Parameters as constructor fields
  @override
  Widget build(BuildContext context) {
    return Container(...);
  }
}
```

**Benefits:**
- Cleaner separation of concerns
- Easier to test in isolation
- Better performance (separate StatelessWidget instances)
- Easier to add local state if needed later
- More readable and maintainable

- When adding new features to ensure they align with the app's "system monitor" persona

**How to Use:**
Refer to the knowledge base files in `knowledge_base/` to maintain consistency with the project's established design system, voice, and technical architecture. Always consult these files before making significant UI or UX decisions.
