# Micro Manager Project Instructions

## Widget Composition

**DO NOT create `_build*` functions.** Instead, create private widget classes.

❌ AVOID:
```dart
Widget _buildStatusCard(...) {
  return Container(...);
}
```

✅ DO THIS:
```dart
class _StatusCard extends StatelessWidget {
  // Parameters as constructor fields
  @override
  Widget build(BuildContext context) {
    return Container(...);
  }
}
```

**Benefits:**
- Cleaner separation of concerns
- Easier to test in isolation
- Better performance (separate StatelessWidget instances)
- Easier to add local state if needed later
- More readable and maintainable
