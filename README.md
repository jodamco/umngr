# Micro Manager

A monorepo for the Micro Manager Flutter application and related services.

## Project Structure

- **flutter_app/** - Main Flutter application for task and checkpoint management

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio / Xcode (for mobile development)

### Installation

```bash
cd flutter_app
flutter pub get
```

### Running the App

```bash
cd flutter_app
flutter run
```

## Project Guidelines

See [.instructions.md](.instructions.md) for architectural guidelines and coding standards.

## Features

- Goal tracking and management
- Checkpoint-based event tracking
- Task organization
